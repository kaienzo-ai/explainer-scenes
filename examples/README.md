# examples/

> Same 8 patterns, different domains.

The scene files in the parent directory use **DevOps / CI-CD demo content**
because that's one specific audience I think about a lot. The patterns
themselves are domain-agnostic.

This folder shows that — picking 4 of the 8 types and applying them to
**creator-economy / AI-content / workflow** topics instead. Same CSS, same
structure, different copy and numbers.

The point: when you fork this repo, you're forking *patterns*, not a
DevOps content pack. Override the copy, override the CSS custom
properties, and the patterns hold.

| File | Pattern | Applied to |
|---|---|---|
| [`stat-creator.html`](stat-creator.html) | stat | Creator metrics (views, reach) |
| [`compare-workflow.html`](compare-workflow.html) | compare | Manual editing vs AI-assisted pipeline |
| [`flow-content.html`](flow-content.html) | flow | Brief → script → render → publish |
| [`quote-creator.html`](quote-creator.html) | quote | Ship-fast ethos (Reid Hoffman) |

Open each `.html` in a browser, same as the parent scenes.
